### FILE: src/hooks/useOpenCV.ts
This is the most critical hook. Implement fully:

State:
- isLoaded: boolean
- error: string | null
- detectedCorners: number[][] | null  (4 points or null)

On mount:
- Check if window.cv already exists
- If not: dynamically inject <script src="/opencv/opencv.js"> into DOM
- Wait for cv.onRuntimeInitialized callback
- Set isLoaded = true when ready
- On failure: set error = ERROR_MESSAGES.OPENCV_LOAD_ERROR

Export function startDetectionLoop(videoRef, canvasRef):
- Use requestAnimationFrame loop
- Each frame:
  1. Draw video frame to offscreen canvas
  2. Read into cv.Mat via cv.imread
  3. Convert to grayscale
  4. Apply GaussianBlur (5×5, sigma=0)
  5. Apply Canny edge detection (threshold1=75, threshold2=200)
  6. Find external contours (RETR_EXTERNAL, CHAIN_APPROX_SIMPLE)
  7. For each contour: approxPolyDP with epsilon = 0.02 * arcLength
  8. Keep 4-point contours with area > 10% of frame area
  9. Pick largest valid contour
  10. Set detectedCorners (normalized to canvas display size)
  11. Clean up all cv.Mat objects (delete)
- Return stopLoop function

### FILE: src/hooks/useUpload.ts
State:
- isUploading: boolean
- progress: number (0-100)
- error: string | null
- success: boolean

Export function uploadSession(guid, pages):
- Build FormData with all blobs
- Filename pattern: {guid}_{index padded to 2 digits}.jpg
- POST to /api/upload via axios
- Track onUploadProgress → update progress state
- On axios error:
  - error.code === 'ECONNABORTED' → UPLOAD_TIMEOUT
  - response.status === 401 → UPLOAD_UNAUTHORIZED
  - response.status >= 500 → UPLOAD_SERVER_ERROR
  - no response → UPLOAD_NETWORK_ERROR
- On success: set success = true
- Reset isUploading when done
